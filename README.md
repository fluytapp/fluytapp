#  ¡Fluyt v3 está aquí!

**Fluyt** es una app de mensajería gratuita desarrollada por **César Frontiñán** (**aXolotl Team**) que ofrece chat en tiempo real, envío privado de archivos, IA integrada (Niggi con Gemini), perfiles de usuarios, sistema de rachas y mucho más. 

🌐 **Web oficial:** [https://fluytapp.github.io](https://fluytapp.github.io)

## Características
* **Chats en tiempo real y cifrado de extremo a extremo:** Conversaciones individuales y en grupo de alta privacidad.
* **Envío de archivos:** Envío privado de archivos de hasta 200 MB.
* **Niggi (IA):** Asistente con Gemini integrado.
* **Perfiles y rachas:** Sistema de recompensas y personalización.

## 📲 Disponibilidad (v3.5)
1. **Android (APK):** Descarga para Android 6+ en la [web de Fluyt](https://fluytapp.github.io).
2. **Web:** Compatible con cualquier navegador.
