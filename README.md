# 🚀 Fluyt — App de mensajería instantánea

[![Versión](https://shields.io)](https://github.io)
[![Plataforma](https://shields.io)](https://github.io)
[![Web Oficial](https://shields.io)](https://github.io)

**Fluyt** es una app de mensajería gratuita desarrollada por **César Frontiñán** (**aXolotl Team**) que ofrece chat en tiempo real, envío privado de archivos, IA integrada (Niggi con Gemini) y sistema de rachas. 

🌐 **Web oficial:** [https://github.io](https://github.io)

## ✨ Características
* **Chats en tiempo real:** Conversaciones individuales y en grupo.
* **Caja fuerte:** Envío privado de archivos de hasta 200 MB.
* **Niggi (IA):** Asistente con Gemini integrado.
* **Perfiles y rachas:** Sistema de recompensas y personalización.

## 📲 Disponibilidad (v3.5)
1. **Android (APK):** Descarga para Android 6+ en la [web de Fluyt](https://github.io).
2. **Web (Escritorio):** Compatible con Windows, macOS y Linux.
